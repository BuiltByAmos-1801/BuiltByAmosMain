# Amos Anand Portfolio

A modern, responsive portfolio website showcasing the work and skills of Amos Anand, a Web Developer and Python Developer from Ranchi, Jharkhand, India.

## 🚀 Features

- **Responsive Design**: Optimized for all devices using Tailwind CSS
- **Smooth Animations**: Powered by Framer Motion for engaging user experience
- **Contact Form**: Integrated with EmailJS for direct communication
- **Multi-Section Layout**: Includes Hero, About, Skills, Projects, Education, Certifications, Internship, Packages, Google Rating, and Contact sections
- **Fast Performance**: Built with Vite for lightning-fast development and builds

## 🛠️ Tech Stack

- **Frontend**: React 18
- **Routing**: React Router DOM
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: React Icons
- **Email Service**: EmailJS
- **Build Tool**: Vite
- **Linting**: ESLint

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/BuiltByAmos-1801/BuiltByAmosMain.git
   cd amos-anand-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`

## 🚀 Usage

### Development
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

### Preview Production Build
```bash

```

### Lint Code
