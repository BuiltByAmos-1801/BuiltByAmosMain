# Built By Amos — Digital Agency Website

Welcome to the official static website for **Built By Amos**, a founder-led digital agency rooted in Ranchi, Jharkhand. This project demonstrates a polished web presence for web development, local SEO, and digital branding services.

## 🌟 Why this site stands out

- Designed for business clarity, trust, and conversion.
- Built with clean HTML, CSS, and JavaScript.
- Optimized for responsiveness, SEO, and local search.
- Includes service pages, portfolio, blog, pricing, and lead capture.

## 📁 Project Structure

- `index.html` — Home page with hero section, service highlights, and CTAs.
- `about.html` — Story of the agency and founder.
- `services.html` — Service offerings and benefits.
- `portfolio.html` — Showcase of past work.
- `pricing.html` — Transparent pricing packages.
- `contact.html` — Contact details and enquiry access.
- `blog.html` — Blog index page.
- `thank-you.html` — Post-conversion acknowledgement page.
- `website-development-ranchi.html` — Website development landing page for Ranchi.
- `local-seo-ranchi.html` — Local SEO landing page for Jharkhand businesses.
- `blog/` — Individual content pieces for digital marketing and SEO topics.

## 🎨 Assets & Code

- `styles.css` — Custom website styles and visual polish.
- `script.js` — Interactive mobile menu, animation reveals, and particle effects.
- `images/` — Brand and hero visual assets.
- `robots.txt` — Crawling instructions for search engines.
- `sitemap.xml` — Sitemap for indexing and SEO.

## 🚀 Features

- Responsive mobile-first design using Tailwind CSS.
- Smooth section reveals and visual micro-interactions.
- Custom cursor glow and animated particle background.
- SEO-ready metadata, Open Graph tags, and structured data.
- Local business positioning for Ranchi and Jharkhand.

## ✅ How to use

1. Open `index.html` in a browser to preview the site.
2. Customize text, images, pricing, and contact details.
3. Deploy as a static website on GitHub Pages, Netlify, Vercel, or any web host.

## 💡 Notes

- No build tools are required — the website is fully static.
- Keep the `images/` folder intact for proper asset loading.
- Update email, phone, and social links in the HTML files when needed.
